# Budgeting

Before changing how money is assigned, spent, shared, or carried forward:

1. Read the [glossary](../GLOSSARY.md) for terminology and accounting rules.
2. Find and read the relevant [architecture decisions](../architecture-decision-records/).
3. Trace the current behavior. Deterministic accounting operations may be in `src/domain/`; services and persistence may be in `src/server/`.

For YNAB reference material, start with the [YNAB links](../ynab-indexes/ynab-links.md).
