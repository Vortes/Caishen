# Hosted web app with daily background updates

Build a hosted web app usable from phones and desktops, with scheduled daily account updates and reconciliation running independently of either partner's computer. This supports reliable daily operation without requiring an always-on personal machine; the initial model integration uses OpenRouter, while local inference remains a later option. Daily summaries point to one persistent review inbox so unresolved work accumulates in a current list rather than separate daily reports.

Each person receives a brief morning email linking to their private review inbox, defaulting to 8 a.m. in their own timezone. The delivery time is configurable, email can be disabled, and the report shows the latest successful account update.

Actual partner repayments, credit-card payments, and loan payments continue through the users' existing banking or payment apps. This app calculates obligations and records and reconciles payments; it does not initiate bank transfers.
