# Security

Caishen handles bank connections and personal financial data, so please report a vulnerability privately instead of opening a public issue.

## Reporting

Open the repository's **Security** tab and choose **Report a vulnerability**. That opens a private report that only you and the maintainer can see.

Include what you found, how to reproduce it, and what an attacker could reach with it.

## Testing

Test against your own account or a local copy. Do not access, change or delete another person's data on [curate.is](https://curate.is), and do not run automated scans against it.

## Scope

In scope: the code in this repository and the hosted app at curate.is.

Out of scope: vulnerabilities in Clerk, Plaid, Neon, Resend or Vercel themselves. Report those to the vendor.
